# Diandra Anggari | Personal Portfolio

Personal portfolio website of **Diandra Anggari**, Computer Science student at BINUS University and aspiring Front-End Developer & UI/UX Designer.

Designed with a **1989-inspired coastal vintage** look: pastel skies, drifting seagulls, and a dusk-navy dark mode.

🌐 **Live site:** [diandra-anggari.vercel.app](https://diandra-anggari.vercel.app)

## Features

- Responsive layout for desktop, tablet, and mobile
- Light and dark mode with saved preference
- Featured projects carousel with detailed case study pages
- Experience timeline with a scroll-following glow
- Tech stack section covering design, development, data & AI, tools, and methods
- Contact form that opens the visitor's email app with the message pre-filled
- Accessibility basics: skip link, ARIA labels, keyboard navigation, and reduced-motion support

## Featured Projects

## Run Locally

No build step is needed. Clone the repository and open `index.html` in your browser.

```bash
git clone https://github.com/diandranggari/Portofolio.git
cd Portofolio
```
